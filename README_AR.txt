حلال؟ — نموذج أولي لموقع قابل للتثبيت

المزايا:
- واجهة عربية وإيطالية.
- بحث بالباركود عبر Open Food Facts.
- مسح مباشر للباركود في المتصفحات التي تدعم BarcodeDetector (مثل بعض إصدارات Chrome).
- تصوير قائمة المكوّنات ومحاولة استخراج النص عبر Tesseract.js، ثم مراجعة النص يدويًا.
- فرز أولي متشدّد: مكوّن محرّم ظاهر / يحتاج إلى تحقق / لا توجد علامة واضحة لكن الحلال غير مؤكد.
- PWA مع manifest وservice worker.

مهم:
- هذه نسخة أولية وليست شهادة حلال أو فتوى. قواعد الكلمات ليست شاملة، وقد تفوّت مكونات أو تخطئ بسبب قراءة OCR.
- لم يُعتبر المنتج حلالًا بشكل نهائي حتى عندما لا تُكتشف كلمات مثيرة للشك.
- تحتاج الكاميرا والتثبيت إلى استضافة HTTPS (أو localhost أثناء التطوير).
- البحث بالباركود وOCR يحتاجان إلى اتصال إنترنت.
- OCR العربية قد يتطلب تنزيل بيانات لغة إضافية وقد لا يعمل في كل البيئات.

التشغيل محليًا:
1. فك ضغط الملف.
2. من مجلد المشروع شغّل خادمًا محليًا، مثل:
   python -m http.server 8000
3. افتح http://localhost:8000 في المتصفح.

النشر:
ارفع محتويات المجلد إلى استضافة تدعم HTTPS والملفات الثابتة (مثل GitHub Pages أو Netlify).
بعد النشر، افتح الرابط في Chrome على Android ثم قائمة المتصفح > Add to Home screen / تثبيت التطبيق.

المصدر الخارجي لبيانات المنتجات:
Open Food Facts API: https://world.openfoodfacts.org/data
